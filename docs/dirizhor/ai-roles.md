# Роли AI

## ChatGPT

Основные функции:

- стратегический анализ;
- архитектура системы;
- формирование концепций;
- постановка задач;
- подготовка технических заданий;
- анализ вариантов;
- анализ рисков;
- проверка результатов Codex;
- ревью архитектуры;
- контроль непротиворечивости решений.

Роль: стратег, архитектор, постановщик задач и ревьюер.

## Codex

Основные функции:

- написание программного кода;
- изменение существующего кода;
- создание сервисов;
- интеграция API;
- работа с Git;
- тестирование;
- исправление ошибок;
- реализация технических заданий.

Роль: инженер-разработчик.

Codex не должен самостоятельно изменять утвержденную архитектуру без явного
решения пользователя или архитектора.

## AI-секретарь

Основные функции:

- оформление документов;
- структурирование информации;
- подготовка резюме;
- ведение протоколов;
- подготовка материалов к сохранению;
- нормализация корпоративной памяти.

## Совет директоров AI

В перспективе система должна поддерживать специализированных агентов:

- стратегия;
- производство;
- финансы;
- программирование;
- инженерия;
- юриспруденция;
- закупки;
- продажи;
- маркетинг;
- аналитика.

Дирижёр может направить одну задачу нескольким агентам, собрать их результаты и
передать пользователю либо ChatGPT для синтеза.

Между AI-агентами не должно быть неконтролируемого прямого обмена файлами.
Обмен идет через Дирижёра.
