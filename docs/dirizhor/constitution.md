# Конституция проекта «Дирижёр»

## 1. Корпоративная память является главным активом

Система строится вокруг корпоративной памяти компании, а не вокруг конкретной
AI-модели или поставщика AI.

## 2. AI-модели заменяемы

Ни один AI-провайдер не должен становиться критической частью системы. Замена
модели не должна приводить к потере корпоративной памяти, документов, истории
решений, структуры проектов, журналов или бизнес-знаний.

## 3. Дирижёр является единой точкой управления

ChatGPT, Codex и другие AI-агенты не должны получать бесконтрольный прямой
доступ ко всей корпоративной памяти. Доступ проходит через Дирижёра.

## 4. Пользователь принимает окончательные решения

Дирижёр и AI-агенты помогают анализировать, реализовывать, проверять и
оформлять результаты. Они не принимают бизнес-решения вместо пользователя.

## 5. Действия должны журналироваться

Операции с памятью, агентами, документами, версиями и результатами AI должны
фиксироваться в журнале.

## 6. Данные должны быть версионируемыми

Документы, решения, результаты AI и изменения корпоративной памяти должны иметь
историю и версии.

## 7. Архитектура не пересматривается без явного запроса

Если пользователь говорит «Продолжаем Дирижёра», подтвержденная архитектура из
этого репозитория считается действующей. Codex не должен заново предлагать уже
утвержденные базовые решения без прямого запроса пользователя.
