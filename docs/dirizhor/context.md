# Проект «Дирижёр»: подтвержденный контекст

## Назначение

Пользователь проектирует независимую корпоративную AI-платформу «Дирижёр».

Главная идея: главным активом системы является не конкретная AI-модель, а
корпоративная память компании. AI-модели должны быть заменяемыми модулями.

Дирижёр является единственной точкой взаимодействия между пользователем,
AI-агентами и корпоративной памятью:

```text
Пользователь -> Дирижёр -> AI-агенты -> корпоративная память
```

## Основная архитектурная модель

Пользователь общается только с Дирижёром.

Дирижёр:

- принимает запрос пользователя;
- понимает задачу;
- определяет, какой контекст необходим;
- обращается к реестру корпоративной памяти;
- получает необходимые документы и данные;
- передает их соответствующему AI-агенту;
- получает результат;
- при необходимости направляет результат другому агенту;
- организует проверку результата;
- возвращает итог пользователю;
- сохраняет новые знания;
- журналирует действия.

Дирижёр не принимает бизнес-решения вместо пользователя. Окончательные решения
принимает пользователь.

## Базовый жизненный цикл задачи

```text
Пользователь
-> Дирижёр
-> ChatGPT: анализ
-> Codex: реализация
-> ChatGPT: проверка
-> AI-секретарь: оформление
-> корпоративная память
```

При необходимости могут подключаться дополнительные специализированные
AI-агенты.

## Инфраструктурные ориентиры

Базовая инфраструктура:

- собственный Linux-сервер;
- Ubuntu Server LTS;
- около 64 GB RAM;
- около 4 TB NVMe SSD;
- Docker;
- PostgreSQL;
- файловое или объектное хранилище;
- Git;
- журналирование;
- резервное копирование;
- API-шлюз;
- очередь задач;
- модуль памяти;
- модуль авторизации;
- модуль AI-интеграций.

Основной пользовательский интерфейс должен быть удобен с телефона и компьютера.
