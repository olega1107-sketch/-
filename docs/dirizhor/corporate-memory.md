# Корпоративная память

## Назначение

Корпоративная память принадлежит компании и должна находиться на собственной
инфраструктуре. Она существует независимо от ChatGPT, Codex или другого
поставщика AI.

## Состав памяти

Корпоративная память должна содержать:

- каталог тем;
- проекты;
- документы;
- протоколы;
- решения;
- историю решений;
- версии документов;
- открытые вопросы;
- результаты исследований;
- связи между документами;
- связи между проектами;
- историю изменений;
- результаты работы AI.

## Реестр корпоративной памяти

Для каждого документа или объекта памяти должен существовать короткий индекс.

Минимальная карточка объекта:

- ID;
- название;
- тема;
- проект;
- расположение файла;
- тип файла;
- дата;
- версия;
- автор;
- краткое содержание;
- ключевые слова;
- связи с другими объектами.

Краткое содержание может быть очень коротким: одно-два слова или короткая
фраза.

## Принцип выборки контекста

AI не должен каждый раз читать всю корпоративную память.

Сначала Дирижёр предоставляет агенту реестр. Агент анализирует реестр и
сообщает, какие документы нужны для выполнения задачи. После этого Дирижёр
получает именно эти документы и передает их агенту.

Это минимизирует:

- объем контекста;
- количество токенов;
- время обработки;
- вероятность информационного шума.
